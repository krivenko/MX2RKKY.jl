# MX2RKKY

MX2RKKY is a Julia implementation of the Monte Carlo algorithm used to study
magnetic order in an XY-model on a triangular lattice with a long-range chiral
interaction between local magnetic moments.

Documentation for [MX2RKKY](https://github.com/krivenko/MX2RKKY.jl).
